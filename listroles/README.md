# ListRoles

Lista todos los roles del servidor con su nombre e ID.

> Prefijo de ejemplo `!` (el de La Trini). Si un comando es hibrido tambien funciona con `/` tras `!slash enablecog <cog>` y `!slash sync`.

## Instalacion

```
!repo update killerbite-cogs
!cog install killerbite-cogs listroles
!load listroles
```

**Requisitos:** Ninguno.

## Puesta en marcha paso a paso

1. Carga el cog.
2. Ejecuta `!listroles`. Muestra cada rol con su ID (util para configurar otros cogs que piden IDs).

## Referencia completa de comandos

Prefijo `!` como ejemplo. `<obligatorio>` · `[opcional]` · `[x=valor]` valor por defecto.

| Comando | Descripcion | Permiso |
|---|---|---|
| `!listroles` | List all server roles with their name and ID. | Todos |
